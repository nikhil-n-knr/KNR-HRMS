# KNR-Hrms Project Management Module Overview

This document provides a high-level overview of the Project Management system within KNR-Hrms.

## Module Structure

The Project Management system is divided into several sub-modules, each handling a specific aspect of the project lifecycle.

| Sub-Module | Purpose | Primary Components |
|------------|---------|--------------------|
| **Projects** | Core project lifecycle management. | `Project.php`, `ProjectController.php` |
| **Tasks** | Granular work unit tracking. | `Task.php`, `TaskController.php`, `Board.vue` |
| **Sprints** | Iteration management for Agile workflows. | `Sprint.php`, `SprintController.php` |
| **Code & Repos** | Git repository integration & commit tracking. | `GitRepository.php`, `DevOps/Dashboard.vue` |
| **Bug Tracker** | Specialized issue and bug tracking. | `BugTicket.php`, `BugTrackerController.php` |
| **Client Hub / Portal** | Stakeholder communication and tracking. | `Client.php`, `ClientPortal/` |
| **Workflow Architect** | Custom lifecycle and approval definitions. | `Workflow.php`, `WorkflowArchitectController.php` |
| **Intelligence** | AI-driven analysis and insights. | `ReviewIntelligenceTab.vue`, `BugAnalyticsController.php` |
| **Pending Approvals**| Centralized sign-off management. | `Approvals/Index.vue` |
| **Deployment Pulse** | Devops monitoring and release tracking. | `PulseTab.vue`, `DeploymentController.php` |
| **Visual Planner** | Advanced visual scheduling and reporting. | `Planner/`, `GanttChart.vue`, `ResourceMatrix.vue` |
| **Documents** | File Management & Timesheet Integration. | `ProjectDocument.php`, `Timesheet.php` |

## Key Concepts

- **Thin Controllers, Fat Services**: All business logic resides in Services (e.g., `ProjectService`).
- **Glassmorphism UI**: High-end UI with `bg-white/80 backdrop-blur-xl`.
- **RBAC**: Every action is protected by `v-can`.
- **Service Logging**: Auditing via `LoggerService`.
