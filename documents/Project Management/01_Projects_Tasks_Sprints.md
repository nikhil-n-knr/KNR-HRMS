# Project, Task & Sprint Management

This document details the core work management components of KNR-Hrms.

## Projects

Projects are the top-level container for all work. They define the scope, team, and high-level milestones.

- **Model**: `App\Models\Project`
- **Controller**: `App\Http\Controllers\ProjectManagement\ProjectController`
- **Frontend**: `resources/js/Pages/Project/Dashboard.vue`

### Key Features
- **Project Dashboard**: High-level stats, progress monitoring, and health status.
- **Team Allocation**: Managing assigned employees and roles.
- **Stage Tracking**: Moving projects through various lifecycle stages (`ProjectStage.php`).

## Tasks

Tasks are individual work units associated with a project.

- **Model**: `App\Models\Task`
- **Controller**: `App\Http\Controllers\ProjectManagement\TaskController`
- **Frontend**: `resources/js/Pages/Project/Board.vue`, `MyTasks.vue`

### Workflows
- **Kanban Board**: Drag-and-drop task status management.
- **Checklists**: Nested sub-tasks via `TaskChecklist.php`.
- **Comments**: Real-time communication on tasks (`TaskCommentController.php`).

## Sprints

Sprints enable Agile iteration management within a project.

- **Model**: `App\Models\Sprint`
- **Controller**: `App\Http\Controllers\ProjectManagement\SprintController`
- **Frontend**: Integration with Visual Planner.

### Features
- **Sprint Logs**: Tracking changes and updates within a sprint via `SprintLog.php`.
- **Start/End Dates**: Defining the iteration period.
- **Sprint Goals**: Attaching specific objectives to each iteration.
