# Documents & Timesheet Interconnection

This document explains the relationship between project documentation and employee work logs.

## Documents & File Management

Centralized storage for project-related files, diagrams, and resources.

- **Models**: `ProjectDocument`, `DocumentComponent`, `DocumentTemplate`
- **Controller**: `App\Http\Controllers\ProjectManagement\ProjectController`
- **Frontend**: `resources/js/Pages/Project/Planner/Views/ProjectDocuments.vue`, `resources/js/Pages/Documents/Index.vue`

### Document Categories
The system categorizes documents into several key types for better organization:
- **MOM**: Minutes of Meeting.
- **DFD**: Data Flow Diagrams / Technical Design.
- **Contract**: Legal and project agreements.
- **Design**: UI/UX assets and mockups.
- **Other**: Miscellaneous project resources.

### Features
- **Project Context**: Documents can be linked directly to specific projects or tasks.
- **Access Control**: Permissions via `shared_with` and `shared_with_teams`.
- **Versioning**: Monitoring changes via `DocumentTemplate.php`.

## Timesheets

Employee-level work tracking for project tasks and activities.

- **Model**: `App\Models\Timesheet`
- **Controller**: `App\Http\Controllers\HR\TimesheetController` (or similar)
- **Frontend**: Employee Dashboard and Project Detail views.

### Relationship & Interconnection

The Timesheet and Document modules are interconnected via the **Project** and **Task** models.

| Data Relationship | Linkage |
|-------------------|---------|
| **Project Link**  | `ProjectDocument.project_id` <--> `Timesheet.project_id` |
| **Task Link**     | `Timesheet.task_id` <--> `Task.id` |
| **Employee Link** | `ProjectDocument.uploader_id` <--> `Timesheet.employee_id` |

### Workflow Integration
1. **Reporting to Docs**: Completed timesheets for specific milestones can generate project reports (`ProjectReports.vue`) which are then saved as project documents.
2. **Task-Specific Documentation**: When an employee logs time against a task, they can attach/refer to documents relevant to that task.
3. **Visibility**: Documents uploaded via the Document Hub can be set to be visible on the Project Dashboard, and vice versa.
